# OnHandBestFit V1

OnHandBestFit selects an appropriate registered Provider for a structured capability requirement. It supports Skill, Module, and CLI Providers; runs standalone; and includes an Agent Skill surface for Host integration.

Selections return a portable result. Matching is deterministic and fails closed when inputs are invalid, stale, insufficient, or incompatible. The release was tested with WorkBuddy.

OnHandBestFit selects Providers; it does not execute them.
